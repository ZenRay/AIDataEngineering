## 📝 核心命令速查

```bash
# 创建 worktree（新分支）
git worktree add <路径> -b <新分支名>

# 创建 worktree（已有分支）
git worktree add <路径> <已存在分支>

# 查看所有 worktree
git worktree list

# 删除 worktree
git worktree remove <路径>

# 清理已删除的 worktree 引用
git worktree prune
```

---

## ⚠️ 重要提醒

1. **Submodule 初始化**：每个新 worktree 都需要手动执行 `git submodule update --init --recursive`
2. **direnv 配置**：每个新 worktree 都需要 `direnv allow`
3. **分支唯一性**：不能有两个 worktree 同时检出同一分支
4. **定期清理**：用完后记得 `git worktree remove` 清理

## 💡 小贴士

1. **命名规范**：worktree 目录名建议 `<仓库名>-<用途>`
2. **位置选择**：推荐放在主仓库的父目录下，便于管理
3. **实验性开发**：worktree 非常适合大胆的实验性重构
4. **并行开发**：同时开发多个特性时，每个特性一个 worktree
